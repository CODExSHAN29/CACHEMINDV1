# @cachemind/sdk — TypeScript Client

Official TypeScript & Node.js SDK for CacheMind Semantic Caching Gateway.

- `CacheMindClient` with `chat.completions.create`, `cache.purge`, `cache.warm`
- Telemetry extraction (`cachemind.status`, `similarity_score`, `tokens_saved`)
- Tags / namespace support via `X-CacheMind-*` headers
